# student-record-system
This is a beginner-friendly Python mini project created as part of learning
Python programming and Object-Oriented Programming (OOP).

## Features
- Takes student name and marks as input
- Uses OOP (Student class)
- Displays pass/fail result

## Technologies Used
- Python

- GitHub version control
